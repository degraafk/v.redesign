# VOX · concepto de rediseño
Sitio estático (HTML/CSS/JS, sin build).

## Probar en local
    npx serve .

## Desplegar en Vercel
    npm i -g vercel
    vercel --prod

Sustituye el contenido de ejemplo (noticias, agenda, delegaciones) por datos reales y conecta el formulario de afiliación y las donaciones a una pasarela de pago propia.
